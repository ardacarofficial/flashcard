## C. Redesign priorities

1. **Unify Study.** Every generic entry opens one deck-scoped chooser: Review due, Learn, Test, Match, Practice today’s words. Show eligible counts, scheduling effects and a named Resume action. Explicit mode buttons may bypass the chooser. Rust should provide eligibility, empty reasons, next availability and distinct reviewed card IDs for the local study day. Default re-study to trial.
2. **Make revealing reversible and grading deliberate.** Space toggles faces repeatedly, digits grade after reveal, H hints, Z undoes a grade. Ignore key repeat and respect focused controls. Show “Hide until tomorrow”, “Pause until resumed” and “Unseen”. This is UI work.
3. **Give vocabulary fields explicit roles in Rust.** Use meaning for grading and editing. For *went*, show “I ___ home” using the captured occurrence and surface form. Fall back to a letter clue when the match is ambiguous. Render labelled Meaning, Example and Source sections. Preserve custom templates.
4. **Organize by task.** Put Single word, Paste and Import file together with destination, field mapping and preview. Lead Statistics with difficult words to practise and Planning with next week’s workload. Settings should show a real example, scope and consequence per choice. Put template code behind Advanced. Offer named provider presets, key entry and connection testing. Give MCP a client-specific setup and Automation editable recipes with preview. Most changes are UI-only. I’d rule out another theme pass and a separate OpenRouter engine.
